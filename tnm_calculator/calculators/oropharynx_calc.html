N Staging: HPV+ vs HPV- Comparison

HPV-Positive (Simpler)

N0: No nodes
N1: One or more ipsilateral nodes, all ≤6 cm
N2: Bilateral or contralateral nodes, any >3 cm but all <6 cm
N3: Any node >6 cm
Note: ENE doesn't change imaging N stage for HPV+

HPV-Negative (Complex)

N0: No nodes
N1: Single ipsilateral ≤3 cm, no ENE
N2a: Single ipsilateral >3 to 6 cm, no ENE
N2b: Multiple ipsilateral, all <6 cm, no ENE
N2c: Bilateral or contralateral, all <6 cm, no ENE
N3a: Any node with clinical ENE
N3b: Any node >6 cm

Key Imaging Tips

Carotid Encasement

<180°: Contact only
180-270°: Abutment
>270°: Encasement (T4b)

Only >270° counts as T4b!

Node Measurement

Always measure SHORT AXIS (perpendicular to long axis)

• Standard threshold: >1 cm
• Level II: >1.5 cm acceptable

Skull Base Assessment

Use bone windows to check:

• Clivus
• Petrous apex
• Pterygoid plates
• Foramen ovale/spinosum

Tongue Muscles

Extrinsic = T4a:

• Genioglossus
• Hyoglossus
• Styloglossus
• Palatoglossus

Intrinsic ≠ T4a

ENE Recognition

Look for:

• Irregular/spiculated margins
• Fat infiltration
• Matted nodes
• IJ thrombosis

Retropharyngeal Nodes

Don't forget these!

They count as regional nodes for oropharynx. Check the retropharyngeal space on every case.

Common Pitfalls to Avoid

1
Not confirming HPV status

The staging systems are completely different. Always check pathology.

2
Measuring nodes on long axis

Use SHORT axis only. This is the standard for nodal measurements.

3
Overcalling carotid encasement

Contact or abutment (≤270°) is NOT T4b. Must be >270° circumferential.

4
Confusing intrinsic vs extrinsic tongue muscles

Only EXTRINSIC muscles = T4a (genioglossus, hyoglossus, styloglossus, palatoglossus).

5
Missing retropharyngeal nodes

These count! Systematically check the retropharyngeal space.

6
Not evaluating ENE in HPV-negative

ENE upstages to N3a in HPV-negative disease (clinical ENE).

7
Forgetting contralateral assessment

Bilateral/contralateral nodes significantly affect N staging.

8
Including edema in tumor size

Measure only the enhancing soft tissue component, not surrounding edema.

Systematic Reading Approach

1
Check HPV Status First

Look at pathology report before starting imaging review

2
Rule Out T4b

Check skull base (bone windows), carotid encasement, prevertebral fascia, mediastinum

3
Rule Out T4a

Check larynx, extrinsic tongue muscles, medial pterygoid, hard palate, mandible

4
Measure Tumor Size

Maximum dimension in any plane on post-contrast images

5
Systematic Nodal Survey

Levels I-VII + retropharyngeal. Measure short axis, count nodes, assess laterality

6
Look for ENE

Irregular margins, fat infiltration, matted nodes (matters for HPV-)

7
Check for Distant Mets

Visible lungs, liver, bones on current study
