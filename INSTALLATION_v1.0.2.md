# FRCR Examiner v1.0.2 - Installation Guide

**For Medical Professionals - Simple & Professional**

---

## 🎯 Quick Summary

FRCR Examiner now has professional installers for both macOS and Windows. No terminal, no technical knowledge required. Just download and double-click!

---

## 📱 macOS Installation

### Step 1: Download
- Download **FRCR-Examiner-macOS-v1.0.2.dmg** from the GitHub releases page

### Step 2: Install
1. Double-click the `.dmg` file
2. A folder window opens showing:
   - **INSTALL.command** (the installer)
   - Application files (templates, static, dist, etc.)

3. Double-click **INSTALL.command**
   - Terminal opens automatically
   - Installation begins

4. Follow the prompts:
   - Press Enter to continue
   - Wait for dependencies to install (takes 2-3 minutes)
   - Installation completes

### Step 3: Launch
- Open **Finder** → **Applications**
- Look for **FRCR Examiner.app**
- Double-click to launch

Or use **Spotlight Search**:
- Press **Cmd + Space**
- Type "FRCR"
- Press Enter

### First Launch Warning
macOS may ask: "macOS cannot verify the developer"
- Click **Open** when prompted
- You only need to do this once!

---

## 🪟 Windows Installation

### Step 1: Download
- Download **FRCR-Examiner-Windows-v1.0.2.zip** from the GitHub releases page

### Step 2: Extract
1. Right-click the ZIP file
2. Select **Extract All**
3. Choose where to extract (default is fine)
4. Wait for extraction to complete

### Step 3: Install
1. Open the extracted folder
2. Find **install-pro.bat**
3. Double-click **install-pro.bat**
   - A command window opens
   - Installation begins automatically
   - This will take 3-5 minutes
   - Follow any prompts

### Step 4: Launch
- Look on your **Desktop** for **FRCR Examiner** shortcut
- Double-click to launch

Or from **Start Menu**:
- Click Start
- Search for "FRCR Examiner"
- Click to launch

## ⚙️ System Requirements

### macOS
- ✓ macOS 10.14 (Mojave) or later
- ✓ Python 3.8+ (installer checks for this)
- ✓ 500MB free disk space

### Windows
- ✓ Windows 10 or later
- ✓ Python 3.8+ (installer checks for this)
- ✓ 500MB free disk space

### Important: Python Installation

**If you don't have Python:**

**macOS:**
1. Visit https://www.python.org/downloads/
2. Download macOS installer
3. Run the installer
4. Then run FRCR Examiner installer

**Windows:**
1. Visit https://www.python.org/downloads/
2. Download Windows installer
3. Run the installer
4. **IMPORTANT**: Check "Add Python to PATH" during installation
5. Then run FRCR Examiner installer

## 🆘 Troubleshooting

### macOS: "Cannot open INSTALL.command"
**Solution:**
1. Right-click INSTALL.command
2. Select "Open"
3. Click "Open" in the dialog that appears
4. This only needs to happen once

### Windows: "Python is not found"
**Solution:**
1. Install Python from https://www.python.org/
2. **Important**: Select "Add Python to PATH" when installing
3. Then run the installer again

### Installation is slow
**Normal:** First installation takes 3-5 minutes while Python packages download
- This is normal, don't close the window
- Be patient!

### App won't start
**Solution:**
1. Check internet connection (needed for first run)
2. Check that Python 3.8+ is installed: `python --version`
3. Try restarting your computer
4. Reinstall if problems persist

## 📁 Installation Locations

**macOS:**

**Windows:**
- Application: `C:\Program Files\FRCR-Examiner\`
- Data stored: Locally in the installation folder

## 🗑️ Uninstallation

**macOS:**
1. Open Finder → Applications
2. Drag FRCR Examiner.app to Trash
3. Empty Trash

**Windows:**
1. Open Control Panel → Programs
2. Find "FRCR Examiner"
3. Click Uninstall
4. Confirm removal
