# FRCR Examiner v2.1 - Release Summary

**Date:** January 7, 2026
**Version:** v2.1.0
**Release Type:** Major Update - Simplified Installation

## 🎯 What's Changed

### ❌ Removed
- PyInstaller build process (complex, version-prone)
- Pre-compiled executables (deployment target issues)
- Build scripts and spec files
- Complex installer creation process

### ✅ Added
- `install_and_run.sh` - Automated installer for macOS/Linux
- `install_and_run.bat` - Automated installer for Windows
- `INSTALLATION.md` - Comprehensive setup guide
- `RELEASE_NOTES_v2.1.md` - Quick start guide

## 🚀 How Users Install

**Simple 3-step process:**

1. Install Python 3.9+ (https://www.python.org/downloads/)
2. Extract FRCR-Examiner-v2.1-Source.zip
3. Run the installer:
   - macOS/Linux: `bash install_and_run.sh`
   - Windows: Double-click `install_and_run.bat`

**Done!** App launches automatically with browser opening to http://localhost:5000
