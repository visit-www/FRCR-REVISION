  FRCR Examiner - macOS Installation Instructions
═══════════════════════════════════════════════════════════════

IMPORTANT: macOS will block this app because it's not code-signed.
Follow these steps to install and run it:

STEP 1: INSTALL THE APP
───────────────────────
1. Drag "FRCR Examiner.app" to the Applications folder (on the left)
2. Wait for the copy to complete

STEP 2: FIX GATEKEEPER (Choose ONE method)
───────────────────────────────────────────

METHOD A: Right-Click Method (Easiest) ⭐ RECOMMENDED
──────────────────────────────────────────────────────
1. Open Finder
2. Go to Applications folder
3. Find "FRCR Examiner.app"
4. RIGHT-CLICK (or Control+Click) on it
5. Select "Open" from the menu
6. Click "Open" in the security dialog
7. The app will launch and be trusted!

METHOD B: Terminal Command (Quick)
───────────────────────────────────
1. Open Terminal (Applications > Utilities > Terminal)
2. Copy and paste this command:
   
   sudo xattr -rd com.apple.quarantine "/Applications/FRCR Examiner.app"
   
3. Press Enter
4. Enter your password (you won't see it as you type)
5. Press Enter again
6. Now double-click the app to open it

METHOD C: Use the Fix Script
─────────────────────────────
1. Download fix-and-open.sh from the GitHub release
2. Open Terminal
3. Navigate to where you downloaded it:
   cd ~/Downloads
4. Make it executable:
   chmod +x fix-and-open.sh
5. Run it:
   ./fix-and-open.sh
6. Enter your password when prompted

STEP 3: LAUNCH THE APP
───────────────────────
After completing Step 2, you can now:
- Double-click "FRCR Examiner" in Applications
- Or use Spotlight: Press Cmd+Space, type "FRCR Examiner", press Enter

═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

If you see "App is damaged and can't be opened":
───────────────────────────────────────────────
1. Open Terminal
2. Run these commands:
   
   sudo xattr -rd com.apple.quarantine "/Applications/FRCR Examiner.app"
   sudo chmod -R 755 "/Applications/FRCR Examiner.app"
   
3. Try opening the app again

If the app still won't open:
────────────────────────────
1. Go to System Settings > Privacy & Security
2. Scroll down to Security section
3. Look for a message about "FRCR Examiner"
4. Click "Open Anyway" or "Allow"
5. Confirm by clicking "Open"

If you see "You don't have permission":
──────────────────────────────────────
1. Right-click the app
2. Select "Get Info"
3. Under "Sharing & Permissions", make sure you have "Read & Write" access
4. If not, click the lock icon, enter password, and change permissions

═══════════════════════════════════════════════════════════════
WHY DOES THIS HAPPEN?
═══════════════════════════════════════════════════════════════

macOS Gatekeeper protects your Mac by blocking apps from 
unidentified developers. Since this app is distributed outside 
the Mac App Store and isn't code-signed with an Apple Developer 
certificate ($99/year), macOS adds a "quarantine" attribute.

This is NORMAL and SAFE - the app is open source and you can 
review the code on GitHub.
