## Getting Started

### First Time Using the App?

1. **Open the app** - Go to `http://localhost:5000` (or your app URL)
2. **See the Dashboard** - You'll see three main cards:
   - **Setup & Prepare** - Create sessions and organize cases
   - **Start Exam** - Begin examining candidates
   - **Administration** - Manage backups and settings

3. **Click "Get Started"** to begin creating your first exam session

---

## Creating an Exam Session

### What is a Session?
A session is like a container for one day's exams. It holds all the candidates, cases, and packets for that day.

### How to Create a Session?

1. **Click "Manage Sessions"** in the navigation bar (or "Get Started" on dashboard)
2. **Click "Create New Session"** button
3. **Fill in the details**:
   - **Session Name**: e.g., "FRCR Viva January 2026"
   - **Exam Date**: Select the date
   - **Exam Time**: Select the start time
4. **Click "Create Session"** button
5. **Done!** Your session is now created

---

## Managing Your Session

### What Can You Do Here?

You can:
- ✅ Add exam packets (groups of cases)
- ✅ Add medical cases with images
- ✅ Register candidates
- ✅ Create Q&A pairs for discussion

### How to Manage a Session?

1. **Go to Sessions** - Click "Manage Sessions"
2. **Find Your Session** - See the session card you created
3. **Click "Manage Session"** button
4. **You'll See Two Sections**:

#### Section 1: Manage Packets & Cases
- **Add Packet**: Click "+ Add Packet" to create a new packet
- **Edit Cases**: Click on a case to add images and questions
- **Add Q&A**: When editing a case, add questions and answers
- **Upload Images**: Drag and drop medical images
- **Add Description**: Describe each case's diagnosis and findings

#### Section 2: Manage Candidates
- **Add Candidate**: Click "+ Add Candidate"
- **Fill Details**:
  - Candidate Name: Full name
  - Candidate Number: 1, 2, 3, or 4
  - Packet Number: Which packet they'll be examined on
- **Click "Add Candidate"**
- **Done!** Candidate is registered

### Tips for Adding Cases

1. **Click "+ Add Case"** in a packet
2. **Add Case Details**:
   - Case Title: Brief name of the case
   - Case Description: Clinical history and presentation
   - Diagnosis: Final diagnosis
3. **Add Images**:
   - Upload X-rays, CT scans, or other images
   - Add descriptions to each image
4. **Add Q&A Pairs**:
   - Questions: What you'll ask the candidate
   - Answers: What you expect them to know
5. **Click "Save Case"**

## Starting an Exam

### Ready to Examine a Candidate?

1. **Click "Exam"** in the navigation bar
2. **Select Session** - Choose the exam session from the cards
3. **Select Candidate** - Choose which candidate to examine
4. **Click "Start Exam"** - The exam will open

---

## During the Exam

### What You'll See

1. **Case Information**:
   - Medical images
   - Clinical history
   - Diagnosis

2. **Discussion Points**:
   - Key points to discuss with the candidate

3. **Q&A Section**:
   - Questions to ask
   - Expected answers for reference

### Tips During Exam

- **Review Images**: Click on images to see them clearly
- **Check Expected Answers**: Use these as a guide
- **Take Notes**: Keep notes of candidate responses
- **Move Between Cases**: Navigate between different cases in the packet
- **Go Back Home**: Click "Home" to return to dashboard

## Tips & Tricks

### 💡 Helpful Tips

1. **Before the Exam Day**:
   - Create your session a day or two before
   - Add all cases and images
   - Register all candidates
   - Review Q&A pairs to ensure they're good

2. **Image Management**:
   - Use clear, high-quality medical images
   - Add detailed descriptions
   - You can update descriptions anytime
   - Images can be added or removed from cases

3. **Q&A Best Practices**:
   - Write clear, specific questions
   - Provide comprehensive expected answers
   - Update answers based on feedback
   - Keep discussions focused and relevant

4. **Candidate Management**:
   - Assign different packets to different candidates
   - Each candidate gets unique cases to discuss
   - You can view candidate's packet anytime

5. **During Exams**:
   - Have a calm environment
   - Take your time reviewing cases
   - Use the app to stay organized
   - Reference notes as needed

### ⏰ Quick Access

- **Home**: Click logo or "Home" to return to dashboard
- **Sessions**: Click "Manage Sessions" to manage
- **Exams**: Click "Exam" to start examining
- **Admin**: Click "Admin" for backups (if needed)

## Frequently Asked Questions

### Q: How many candidates can I register?
**A**: You can register as many as needed! Usually 1-4 per session.

### Q: Can I change a session's date/time?
**A**: Currently, you need to create a new session. Future versions will allow editing.

### Q: Can I use the same packet for multiple sessions?
**A**: You can, but it's recommended to create new packets for organization.

### Q: How many cases per packet?
**A**: As many as you need! A typical exam packet has 4-10 cases.

### Q: Can I upload videos?
**A**: Currently only images are supported. Focus on high-quality medical images.

### Q: How are backups handled?
**A**: Automatic backups are created every 24 hours. Check Admin for details.

### Q: What if I accidentally delete something?
**A**: Contact the administrator. Backups can help recover deleted data.
