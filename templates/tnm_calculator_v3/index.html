    About TNM Calculator v3

    This new version uses clinically-curated, decision-tree calculators for each disease site. Each calculator guides you through the staging process in the order clinicians think: check worst case first (T4b → T4a → size-based).

    Features include:

    • HPV-specific staging for oropharyngeal cancer
    • Biomarker integration for breast cancer (ER, PR, HER2, Grade)
    • Clinical mnemonics and imaging tips
    • Common pitfalls to avoid
    • Detailed reasoning for each stage assignment
