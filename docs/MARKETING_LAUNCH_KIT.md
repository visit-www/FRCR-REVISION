## 3. Product Features — Full Inventory

### Smart Reporter (AI Reporting Engine)
- **Shorthand to Report**: Type rough shorthand, get consultant-grade PACS-ready report
- **Opus AI (Premium)**: Report finalization, review, rewrite with Claude Opus
- **Sonnet AI (Standard)**: Follow-up questions, teaching points, clinical insights
- **Haiku AI (Quick Check)**: Lightweight spell/grammar review
- **Algorithm Tree Walkthrough**: Step-by-step structured reading guides
- **Report Actions**: Generate SBA questions, Viva scenarios, MDT summaries, GP/patient emails from any report
- **Teaching Points**: AI-generated clinical insights specific to each case
- **Cognitive Trap Detection**: Flags satisfaction of search, anchoring bias
- **Voice Dictation**: Speech-to-text via Groq Whisper (Chrome/Safari)
- **PII Guard**: Automatic patient data detection — blocks API until resolved
- **RadInsight Peer Review**: PubMed verification of AI-generated numerical claims

### RadIQ (AI Clinical Assistant) — 5 Specialist Agents
1. **General Clinical Queries** — Evidence-based imaging guidance
2. **GP Reply Generator** — Draft formal reply letters to referrals
3. **Complaint Response** — NHS duty-of-candour compliant responses
4. **Incident Report (Datix)** — Structured adverse event reports
5. **Radiographer Support** — Protocol queries, contrast safety, technical guidance

### Vetting Tool
- AI analysis of imaging referrals
- Study type recommendation with guideline citation (NICE, RCR iRefer, ACR)
- Protocol generation with technical parameters
- Safety checks (eGFR, pregnancy, allergy)
- Matched protocols from 130+ imaging protocol library

### Case-Based Learning
- Published radiology cases with FRCR-aligned Q&A
- DICOM image stacks (OneDrive integration)
- Viva-style question sets with model answers
- SBA practice with spaced repetition
- Case discussion and teaching points

### Oncology & TNM Staging
- **72 disease sites** (AJCC 8th Edition) with interactive calculators
- T/N/M selection, auto-calculated stage grouping
- Quick reference tables for each cancer type
- Essential TNM concepts education module

### Clinical Tools & Calculators
- **6 Incidental Findings Calculators**: Fleischner 2017, Bosniak v2019, TI-RADS, PI-RADS v2.1, LI-RADS v2018, Adrenal Washout
- **Contrast Reaction Card**: 6-tab ACR-aligned quick reference (premedication, acute reactions, extravasation, renal/CI-AKI, special populations, paediatric calculator)
- **130+ Imaging Protocols**: CT and MRI with technical parameters
- **Paediatric CT Protocols**: Weight-based dose calculators

### Knowledge Hub
- **Anatomy Snippets**: AI-generated reference cards with measurements, variants, imaging pitfalls
- **Radiology Pearls**: High-yield teaching points with verification status
- **Reporting Algorithms**: Interactive decision trees for systematic reading
- **Reporting Templates**: PACS-ready structured templates
- **Global Intelligent Search**: Searches across all 7 content types simultaneously

### My Study Notes
- **Evernote-like organisation**: Notes automatically grouped into Notebooks by content type (Cases, OSCE, TNM, Protocols, etc.)
- **Cross-content retrieval**: Search and filter all your notes from one unified dashboard
- **Notes & Discussion on every page**: Side panel with notes, text highlights, and discussion forum available on 10+ content types
- **Tagging system**: Auto-tags from content metadata (body section, modality) + custom user tags
- **Starred notes**: Pin important notes for quick access during revision
- **Inline editing**: Edit notes directly in the dashboard with auto-save
- **Source linking**: Every note links back to its original content for one-click navigation

### MDT Suite
- Multi-disciplinary team meeting preparation
- AI-generated MDT summaries
- Case organisation by meeting
- Linked case workflows

### Safety & Trust
- **PII Guard**: 28 regex patterns + NHS MOD-11 checksum for patient data detection
- **RadInsight Peer Review**: PubMed verification of AI claims with green/amber trust badges
- **Two-Factor Authentication**: TOTP 2FA for admin accounts
- **Audit Logging**: Every AI call tracked with model, tokens, cost
- **UK GDPR Compliant**: Data encrypted, no patient data stored
